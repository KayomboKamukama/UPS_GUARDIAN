# USER GUIDE (Phase 1)

## Navigation
- Dashboard
- Devices
- Alerts
- Reports
- Settings
- About

## Devices
- Add/edit/delete UPS devices.
- Enforce UPS naming format (e.g., `UKYL-3KVA-001`).
- Import/export UPS inventory CSV.
- Search/filter by name/IP/model/station/vendor.

## Polling & Alerts
- Polling runs on an interval and can be triggered manually.
- Mock telemetry simulates UPS behavior for prototype validation.
- Alerts are deduplicated and can be acknowledged with operator/comment.

## Reports
- Export UPS inventory CSV.
- Export active alerts CSV.
- Export latest device status summary CSV.
